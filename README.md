# Armenian Liturgical Calendar and Sharagnots (site)

Static site (GitHub Pages ready). Tabs: **Hymnal** (the Krapar Sharagnots hymnal, search, concordance, transliteration, phrase links,
scripture reference mode, extended with the Unicode-anchored 1888 Sharagnots and a scan-page viewer) and **Calendar** (type any date: commemorations,
mode, fasting, readings, hymns, from the calgen rules engine).

Run locally:   `./run.sh`   then open http://localhost:4190/        (do not open index.html as a file: it loads JSON)
Rebuild data:  `python3 tools/build_data.py && python3 tools/apply_patches.py`
Tests:         `for f in tests/test_*.mjs; do node $f; done` (14 files) and `python3 -m unittest tests.test_hymnal_data tests.test_stanza_fixes tests.test_display_clean tests.test_mode_evidence tests.test_english_choice tests.test_psalm_numbering_ls323`; `tools/deploy.sh` runs them before every push
Docs:          `docs/DATA.md` (data combination rules), `docs/ENGINE_API.md` (calendar engine), `docs/CALENDAR_API.md` (hooks)

Credits: hymnal code, data and design by frharoutiun/Armenian-Church-Tools (sharagan/); fonts GHEA Mariam and EB Garamond (OFL, see fonts/).
AI translations are labelled: "AI translation (Krapar Sharagnots)" (Krapar sections) and "AI translation (Claude)" (the rest); one English per stanza. Scripture: ESV loaded live from the ACHR endpoint (not stored here); RSVCE cached for the Apocrypha only; Armenian verses from Arak29 (1895 Classical Armenian Bible, plain text, attribution in docs/LICENSES.md, used with permission); Sharagnots supplement text from Fr Ghevond Ajemian's Unicode edition (used with permission); KJV (public domain) beside chants. Draft: items marked needs review are unconfirmed.

Live site: https://frharoutiun.github.io/armenian-liturgical-calendar/   (GitHub Pages, repo frharoutiun/armenian-liturgical-calendar)
Redeploy:  `tools/deploy.sh "message"` (tests + publish check + push + live verification). Scripture audio is in a separate repository
(frharoutiun/armenian-liturgical-audio), referenced by `window.LC_AUDIO_BASE` in day-extras.js. See docs/LICENSES.md and status.html.
Calendar tab (calendar.js, day-extras.js): three tabs (Readings, Sharagnots, Notes & sources). Readings: Armenian Bible text (Arak29, matched verse by verse) beside the live ESV (ACHR endpoint; cached RSVCE for the Apocrypha) with a numbering badge, chants interleaved before the reading they introduce, the Jashots printed-page transcription as a collapsed second layer, and a Listen control that works like achrct.org (short spoken introduction, Gospel caption, then Crossway's human-read audio; never chapter and verse). Sharagnots: the day's canon part by part with one scan page per hymn, ode sub-headings and AI English (one per stanza). scripture-match.mjs maps readings to cache keys.
Project status, evidence, commands and review queues: `output/PROJECT_STATUS.md` in the canonical project repo (`06 - Donatsooyts Digitization`); this repo's status page is generated by `tools/build_status.py` at deploy.
